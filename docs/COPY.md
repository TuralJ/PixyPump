# Words we use

Friendly, short, plain English. Talk to the player as "you". Celebrate effort, never shame.
Sentences in sentence case; pixel labels can be UPPERCASE.

| Concept | Always say | Never say |
|---|---|---|
| The app | `AppInfo.name` (PixyPump) | hardcoded name in strings |
| Reward container | gym bag (Epic gym bag) | mystery bag, chest, loot box |
| Streak protection | freeze ❄️ | shield, 🛡 |
| The streak | streak 🔥 (daily) | — |
| Weekly progress | weeks on plan | weekly streak |
| Daily goals | Daily challenges | Today's missions, quests |
| Weekly goals | Weekly missions | — |
| In-workout goals | This workout | Today's missions |
| Long-term path | Journey, chapter, boss | — |
| Personal record | PR, New PR! | Personal best, record (in UI) |
| Level | **LV 5** in badges, **Level 5** in sentences | LV5, lvl |
| End of rest | Rest's over 💪 | Rest done!, Time's up |
| Body weight | Log weight | Weigh in (as a button), Log body weight |
| Skipping optional steps | Skip | Not now, Later |
| Ending a workout | Finish workout | Done, End |
| Ending one exercise | Finish exercise | — |
| Cancelling a workout | Cancel workout | Cancel (alone) |
| First-week list | First week checklist | Getting started, First 3 wins |
| Account | Save your progress, Create account or sign in | Register, Log in (as separate flows) |
| Ending a workout early | Finish workout early (in ···) | End workout |
| Moving on in a workout | Next: Bench press | Continue to…, Go next |
| Leaving workout mode | All exercises | Back, Workout list |
| Looking at another day | Preview, Back to today | View only, Read-only |
| Workout in progress (the screen) | workout mode (docs only) | session (in UI) |
| The paid tier | PixyPump Pro / Pro | Premium, Plus, VIP |
| Paid weekly freeze | streak shield | bonus freeze |
